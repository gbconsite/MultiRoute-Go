# 🎄 Weihnachts-Update: Neue Farbkennzeichnung für Gebäudepunkte

Zum Jahresende haben wir auf vielfachen Kundenwunsch eine praktische Optimierung in unserem Programm umgesetzt – ein kleines Weihnachtsgeschenk, das Ihre tägliche Arbeit noch effizienter macht.

## 🔵 Neue Farbgebung für bessere Übersicht

Bislang wurden aktivierte Gebäudepunkte durch einen **grünen Kringel** markiert. Um die Darstellung klarer und die Unterscheidung einfacher zu gestalten, erscheinen diese Punkte nun in **dunkelblau**.  
Damit lassen sie sich deutlich besser von den **gelb markierten Gebäudepunkten** abheben, die aufgrund [geänderter Hauszugänge](../../gehfolgenoptimieren.md#veranderung-der-straenankerpunkte) gekennzeichnet werden.
<!-- more -->
## 🔍 Verbesserte Darstellung beim Zoomen

Ein zusätzlicher Vorteil:  
Die aktivierten Punkte bleiben **auch beim Herauszoomen dauerhaft sichtbar**. So behalten Sie jederzeit den Überblick – auch über größere Verteilbezirke.

<img width="499" height="341" alt="Blaue Kringel für zugeordnete Gebäude" src="https://github.com/user-attachments/assets/5a67e503-c905-4f2d-ba31-b659bead7593" />

Wenn Sie sich hingegen nur auf einen einzelnen Verteilbezirk konzentrieren möchten, nutzen Sie einfach die Funktion **„Auswahl filtern“** in der linken Seitenleiste. Dadurch wird ausschließlich der gewählte Verteilbezirk angezeigt.  
Mit einem Klick auf **„Auswahl aufheben“** werden anschließend wieder alle Verteilbezirke sichtbar.

## 🚀 Rollout des Updates

Die neue Farbkennzeichnung wird im Rahmen unserer regelmäßigen Updates **schrittweise ausgerollt**.  
Wenn Sie besonders schnell "blau" sehen möchten, sprechen Sie uns gerne an – wir schalten Ihnen nach Möglichkeit die Funktion auf Wunsch früher frei.
